## ✨ Key Features

The portfolio is structured as a series of navigational "Waypoints," utilizing advanced CSS techniques to create a space-faring terminal experience:

*   **System Initiated Hero:** A deep-space landing page featuring a rotating Earth, SVG quantum telemetry logo, glitch typography, and a typewriter subtitle effect.
*   **Academia Checkpoints:** A horizontal, scrollable wavy SVG timeline charting educational history.
*   **Skill Flowcharts & Nebula Clouds:** A visual mapping of technical expertise (Frontend, Backend, Database, AI & Tools) using glowing branch connectors and floating tag animations.
*   **Data Stream Timeline:** A vertical fiber-optic experience timeline highlighting internships and professional roles.
*   **Sci-Fi Project Datapads:** Interactive project cards featuring biometric scanlines, tech-node indicators, and glowing hover states.
*   **Holographic Credentials:** Certification cards that utilize a sweeping glass-glare effect on hover.
*   **Secure Communications Terminal:** A cyberpunk-inspired contact section designed like a retro command-line interface, complete with a pinging radar and animated typing email link.

## 🛠️ Tech Stack

This portfolio is built entirely from scratch without heavy external CSS frameworks to maintain complete control over the animations and layout.

*   **HTML5:** Semantic structuring and inline SVGs.
*   **CSS3:** 
    *   CSS Variables (Custom color theming for Cyan, Neon Purple, and Amber).
    *   Flexbox & CSS Grid for responsive layouts.
    *   Advanced `@keyframes` (Glitch effects, radar pings, levitation, hologram sweeps).
    *   Backdrop-filters for Glassmorphism.
*   **JavaScript (Vanilla):** Dynamic scroll-reveal elements, mobile navigation toggling, and trajectory line tracking.
